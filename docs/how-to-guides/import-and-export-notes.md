# Import and Export Notes

Joplin lets you bring notes in from other apps and take your notes out in several formats — useful for backups, migrating from another note app, or sharing notes outside Joplin.

## Importing notes

1. Go to **File → Import**
2. Choose the format that matches your source file, for example:
   - **JEX** or **RAW** — Joplin's own export formats
   - **ENEX** — Evernote export files (as HTML or Markdown)
   - **HTML**, **MD**, or **TXT** — common document formats
   - **ONE** — OneNote notebooks
3. Select the file (or folder, depending on the format) from your computer
4. Joplin imports the notes into your notebook list
![Import Formats](/img/Import-formats.png)

## Exporting notes

1. Go to **File → Export all**
2. Choose the format you want to export to, for example:
   - **JEX** or **RAW** — for backing up or moving to another
     Joplin instance
   - **MD** or **MD + Front Matter** — plain Markdown files
   - **HTML Directory** — a folder of HTML files
   - **PDF** — a single PDF file
3. Choose where to save the exported file or folder on your computer
![Export formats](/img/export-formats.png)

## Why this matters

Exporting to open formats like Markdown or PDF means your notes aren't locked into Joplin — you can move them to another tool later if needed. Importing support for formats like Evernote's ENEX makes switching to Joplin from another app easier.
