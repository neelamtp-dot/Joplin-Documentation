# Keyboard Shortcuts

A reference of common keyboard shortcuts in Joplin's desktop app.

## File and note actions

| Action | Shortcut |
|---|---|
| New note | `Ctrl+N` |
| New to-do | `Ctrl+T` |
| Synchronise | `Ctrl+S` |
| Close window | `Ctrl+W` |

## Editing

| Action | Shortcut |
|---|---|
| Copy | `Ctrl+C` |
| Cut | `Ctrl+X` |
| Paste | `Ctrl+V` |
| Paste as text | `Ctrl+Shift+V` |
| Paste as Markdown | `Alt+Ctrl+Shift+V` |
| Select all | `Ctrl+A` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` |

## Text formatting

| Action | Shortcut |
|---|---|
| Bold | `Ctrl+B` |
| Italic | `Ctrl+I` |
| Hyperlink | `Ctrl+K` |
| Code | `` Ctrl+` `` |

## Working with lines

| Action | Shortcut |
|---|---|
| Delete line | `Ctrl+D` |
| Duplicate line | `Ctrl+Shift+D` |
| Toggle comment | `Ctrl+/` |
| Sort selected lines | `Alt+Ctrl+S` |
| Indent less | `Ctrl+[` |
| Indent more | `Ctrl+]` |
| Swap line down | `Alt+Down Arrow` |
| Swap line up | `Alt+Up Arrow` |

## Other useful actions

| Action | Shortcut |
|---|---|
| Insert time | `Ctrl+Shift+T` |
| Search in all notes | `F6` |
| Search in current note | `Ctrl+F` |

## Layout and view

| Action | Shortcut |
|---|---|
| Toggle sidebar | `F10` |
| Toggle menu bar | `Ctrl+Shift+M` |
| Toggle note list | `F11` |
| Toggle editor layout | `Ctrl+L` |
| Toggle editors | `Alt+Ctrl+E` |
| Tab moves focus | `Ctrl+M` |
| Actual size (zoom) | `Ctrl+0` |
| Zoom in | `Ctrl++` |
| Zoom out | `Ctrl+-` |
