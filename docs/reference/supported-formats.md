# Supported Import/Export Formats

## Import Formats
| Format | Description |
|---|---|
| JEX | Joplin Export File |
| RAW | Joplin Export Directory |
| ENEX | Evernote Export File (as HTML) |
| ENEX | Evernote Export File (as Markdown) |
| ENEX | Evernote Export Files (Directory, as HTML) |
| ENEX | Evernote Export Files (Directory, as Markdown) |
| HTML | HTML document (File) |
| HTML | HTML document (Directory) |
| MD | Markdown (File) |
| MD | Markdown (Directory) |
| MD + Front Matter | Markdown with Front Matter (File) |
| MD + Front Matter | Markdown with Front Matter (Directory) |
| TXT | Text document (File) |
| TXT | Text document (Directory) |
| ONE | OneNote Notebook |

## Export formats

| Format | Description |
|---|---|
| JEX | Joplin Export File |
| RAW | Joplin Export Directory |
| MD | Markdown |
| MD + Front Matter | Markdown with Front Matter |
| HTML | HTML Directory |
| PDF | PDF File |
