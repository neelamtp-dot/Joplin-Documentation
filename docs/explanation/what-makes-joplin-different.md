# What Makes Joplin Different

Joplin is a note-taking app that lets you create notes, to-do lists,
and notebooks, all written in Markdown. Compared to simpler note apps
like Google Keep or Evernote, Joplin offers a noticeably wider set of
options for organizing and managing your notes.

## Who it's for

Joplin works well across different contexts:

- **Individuals** organizing personal notes and to-do lists
- **Organizations** needing a shared, flexible note-taking tool
- **Students** managing notes across subjects and projects

## Syncing your notes

Joplin supports syncing your notes across devices using several
services, including:

- Joplin Cloud
- OneDrive
- Other supported sync targets

This means your notes aren't locked to a single device.

## Tags across notebooks

Notes can be tagged with keywords, and tags work independently of
notebooks — a note in one notebook can share a tag with a note in a
completely different notebook. Clicking a tag in the left navigation
panel shows every note that has that tag, regardless of which
notebook it belongs to.

## Import and export

Joplin supports importing and exporting notes in several file
formats, making it easier to move data in from other apps or out to
other tools.
