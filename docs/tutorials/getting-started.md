# Getting Started with Joplin
Joplin is a free, open-source note-taking app that lets you create notes, to-do lists, and notebooks — all written in Markdown. This guide walks you through installing Joplin and creating your first note.

## Step 1: Install Joplin
1. Go to [joplinapp.org](https://joplinapp.org)
2. Download the installer for your operating system
3. Run the installer and follow the on-screen prompts

## Step 2: Understand your Options
When users click on **New** button, Joplin gives your four options:

- **New Note**: A standard note, written in Markdown. Use this for most content: documentation, ideas, articles, etc.
- **New To-do**: similar to a note, but includes a checkbox so you can mark it as complete. Use this for tasks and action items.
- **New Notebook**:A top-level folder to organize your notes and to-dos.
- **New Sub-notebook**: A notebook nested inside another notebook, useful for further organizing a topic (for example, a "Recipes" notebook with sub-notebooks for "Breakfast" and "Dinner").
![Joplin New menu open in the app interface, showing the options New Note, New To-do, New Notebook, and New Sub-notebook](/img/joplin-menu.png)

## Step 3: Create First Notebook
1. In the left sidebar, click **New Notebook**
2. Give it a name, for example "My First Notebook"
![Joplin New Notebook in the app interface, showing create pop-up](/img/First-Notebook.png)

## Step 4: Create you first Note
1. With your notebook selected, click **New Note**
2. Type a title for your note
3. Below the title, write your note content using Markdown — for example, use `#` for headings or `-` for bullet points
4. Joplin shows a live preview of your formatted note as you type.
![Joplin note showing both markdown preview and editor](/img/Joplin.png)

## Step 5: Add a Tag
1. Open a note
2. Add a tag using the tag option in the note view
3. Click the tag name in the left sidebar to see every note that shares that tag, regardless of which notebook it's in
![Tags that are created by the user](/img/Tagswindow.png)
