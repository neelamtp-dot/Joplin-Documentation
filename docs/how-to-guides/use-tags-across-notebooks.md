# Use Tags Across Notebooks

Notebooks organize your notes into folders, but sometimes a note
relates to a topic that spans multiple notebooks. Tags solve this —
they let you group related notes together regardless of which
notebook they're stored in.

## Step 1: Add a tag to a note

1. Open a note
2. Find the tag option in the note view
3. Type a tag name and confirm it
![Joplin tag creation window](/img/tags.png)

## Step 2: Add the same tag to a note in a different notebook

Repeat the same process on a note stored in a **different** notebook, using the exact same tag name.

## Step 3: View notes by tag

1. In the left navigation panel, find the **Tags** section
2. Click on the tag name you used
![Tags on the left Navigation window](/img/Tagswindow.png)

Every note with that tag appears together in the results — even though the notes live in separate notebooks.

## Why this is useful

Notebooks work well for broad organization (for example, by project or subject), while tags work well for cutting across that organization (for example, tagging anything "urgent" or "to-review", regardless of which notebook it's filed under).

:::tip
A single note can have multiple tags, so you can combine several ways of grouping the same note without duplicating it.
:::
